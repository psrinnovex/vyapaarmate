# VyapaarMate brand assets

The founder-supplied marks were prepared as transparent PNGs on 5 September 2026.

- `vyapaarmate-logo-light.png`: black/charcoal and green; use on white/light surfaces.
- `vyapaarmate-logo-dark.png`: white/silver and green; use on dark surfaces.

Both are square 1254px RGBA images. Preserve their aspect ratio and select the variant against the immediate background. `BrandMark` provides optimized, accessible rendering throughout mixed-surface pages; browser icons follow the browser's preferred colour scheme.

These are raster derivatives prepared with ImageGen from the founder's supplied artwork, not vector masters. Minor extraction irregularities remain at full size; use the original artwork for further large-format refinement. Do not flatten the PNGs onto an opaque background.
